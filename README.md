# Hospital Management System

## Overview
This project is a console-based Hospital Management System built using Java. It allows users to register patients, schedule appointments, add staff members, and view all records through a user-friendly command-line interface.


## Features
- **Register Patient**: Add new patients with health issues.
- **Schedule Appointment**: Book doctor appointments with time slot validation.
- **Add Staff Member**: Add hospital staff with different roles.
- **View Patients**: List all registered patients.
- **View Appointments**: Display all scheduled appointments.
- **View Staff***: Show all hospital staff members.
- **Exit**: Exit the application safely.

## Prerequisites
- **Java Development Kit (JDK)** installed
- **Eclipse IDE** (or any Java-supported IDE)
- **Git** (for pushing to GitHub)

## How to Run
1. Clone the repository:
2. Open the project in **Eclipse** or any Java IDE.
3. Compile and run the HospitalManagementSystem.java file.

## How to Use
1. Run the program.
2. Choose an option from the menu:
   - Press **1** to register a patient
   - Press **2** toschedule an appointment
   - Press **3** to add a staff member
   - Press **4** to view all patients
   - Press **5** to view appointments
   - Press **6** to view staff
   - Press **7** to exit.
